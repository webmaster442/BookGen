[green bold]BookGen - A C# documentation generator[/]

[italic]BookGen is a command line toolchain for writing books and documentation in markdown. It was inspired by GitBook. 
Generally speaking you can call it a static website generator, but it has some neat features compared to other products.[/]

To get started read the docs by executing the following commands:

* [bold]bookgen documents manual[/]
* [bold]bookgen documents commands[/]

To get help on a command type [bold]bookgen help <command>[/].
